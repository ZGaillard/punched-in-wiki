## Description

Runs the [bar](../shops.md#bar), where the player buys a starting relic
before the run, then relics after each close. A showy mixologist working eight bottles at once.

## Abilities

Sells 3 different [relics](../relics/index.md) before the run and after each close.

## Design notes

- A sea animal, so it overlaps a little with [The Shark](the-shark.md)'s
  biome.
