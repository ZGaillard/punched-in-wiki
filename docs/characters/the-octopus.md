## Description

Runs the [relic shop](../shops.md#relic-shop), a cocktail bar, where the player buys a starting relic
before the run, then relics after each boss game. A showy mixologist working eight bottles at once.

## Abilities

Sells 3 different [relics](../relics/index.md) before the run and after each boss game.

## Design notes

- A sea animal, so it overlaps a little with [The Shark](the-shark.md)'s
  biome.
