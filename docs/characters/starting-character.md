## Description

The basic starting character. The player plays as a raccoon, like
[The Old Raccoon](the-old-raccoon.md), the head chef. Name: TBD.

## Abilities

None.

## Starting menu

15 × [Burger](../menu-items/burger.md). Burgers have no effect. Before the
run, the player makes a first
[menu item choice](../rules/drafting-and-curses.md#menu-item-choice-pick-1-of-3-then-swap).

## Starting relic/consumables

- **Relic:** none built in; the player picks a starting relic at the
  [bar](../shops.md#bar) before the run.
- **Consumables:** none.

## Unlock

Available from the start.
