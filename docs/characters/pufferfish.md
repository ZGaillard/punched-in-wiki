## Description

Buff only.

## Abilities

- **Deflated:** if it moved last turn, it can be hit like any blot.
- **Puffed up:** if it didn't, hitting it sends your hitting order to the pillar too.

Full rules on the [biome page](../biomes/shark.md#minion-2-pufferfish).
