# Punched In — Design Wiki

This wiki is the shared design reference for **Punched In**: every game in it
is a game of classic backgammon, and a run lasts three days (Thursday, Friday,
Saturday), each against one biome's minions and boss, before a final boss,
The Pig, the owner. Use the cards below to jump to a section, or the search
bar to find any term.
