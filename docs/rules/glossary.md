# Glossary

The vocabulary of Punched In. These words are used everywhere in the wiki and
in the game instead of the usual backgammon terms.

Order
:   A checker on the board.

Plate
:   A checker that has been borne off, or a checker outside a game.

Bill
:   A point holding one or more checkers.

Menu
:   The player's whole collection of checkers. See
    [Drafting & curses](drafting-and-curses.md).

Refired
:   A checker that was hit and sent off the board (backgammon's "bar").

Service
:   A regular game against a biome's minions. See
    [Run structure](run-structure.md).

Close
:   A game against a biome's boss.

Tips
:   The in-run currency, spent in the in-run shops.

Dish pit
:   The consumables shop, visited between games. See [Shops](../shops.md).

Bar
:   The relics shop ("shift beer"), visited between days.

Smoke break
:   The pause menu.
